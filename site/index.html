A hard limit.
Not a billing surprise.

Every request checks current model and provider prices. The router allows only verified free models and sends a zero-price cap to OpenRouter.

Free capacity is shared and can run out. When it does, bailout stops or tries another verified free model. It never switches to a paid one.

FAIR QUESTIONS

Before you curl.

What’s the catch with free models?+

Model quality and availability vary. The hosted service shares an OpenRouter quota, so it can rate-limit. This is a small open-source project, not a promise of unlimited inference. You can run your own FastAPI backend with your own key for a separate quota.

Do I need an API key or an account?+

No account or key is needed to use the hosted service. Install the binary and run bailout. The service key stays on the server and is never shipped in the binary.

What can it do on my machine?+

Bailout runs Bash with your user’s permissions. Commands execute automatically, so it can read and edit files, run programs, and access the network. It is not a sandbox. Use a container or disposable checkout when you want isolation.

What leaves my machine?+

Your conversation and tool output go through the API to OpenRouter and the selected model provider. Their data policies apply. Bailout does not save conversations on the server or record prompts in application logs. Keep secrets out of prompts and files the model reads.

Why another coding agent?+

To explore how much a very small agent can do with one general-purpose tool. The client is Rust, the tool is Bash, and the models are free. The source is small enough to read, change, and host yourself. It takes inspiration from Pi’s minimal core and fx’s small native footprint.
