Get your agent back.

OpenCode won’t start after a config edit. The agent you’d normally ask for help is the thing that needs fixing.

Try it on your machine ↗Download video ↗

What happens in the recording

  1. Your usual agent is broken. OpenCode exits with a configuration error before it can answer.
  2. Get a working agent. Run curl -fsSL https://bailout.dev/install.sh | bash, then bailout. No account or local model key.
  3. Ask for a repair. Give Bailout the startup error and ask it to back up and repair the config while keeping the other settings. Bailout diagnoses and repairs the invalid permission setting.
  4. Get back to your agent. Run bailout uninstall. OpenCode now answers through its free Big Pickle model.

One successful session, not a reliability benchmark. Model responses, speed, and free capacity vary. Independent checks also verified the config backup, preservation of the other settings and project file, and OpenCode’s response after uninstall.
