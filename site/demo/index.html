What happens in the recording

  1. Start with missing tools. opencode is not installed.
  2. Get a working agent. Run curl -fsSL https://bailout.dev/install.sh | bash, then bailout. No account or local model key.
  3. Ask it to set up the machine. Ask Bailout to install OpenCode using its official installer URL, then check its version. Authentication is left for the user.
  4. Remove the temporary harness. Run bailout uninstall. OpenCode still runs afterward.

One successful session, not a reliability benchmark. Model responses, speed, and free capacity vary. The installed tools were also verified separately before this recording was published.
